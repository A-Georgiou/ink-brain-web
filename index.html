How it works

Three steps, right on your screen

Press one shortcut and Ink Brain is there, over whatever you are reading, watching or building.

  1. 1

    Circle anything

    Press ⌥⇧Space, then circle, underline or click a figure, an equation or a photo.

  2. 2

    Ask your question

    Speak or type, in your own words. Keep talking for follow-ups, or go hands-free and start with “Ink Brain”.

  3. 3

    See it explained

    It talks you through it with sketches, motion graphics and 3D models, built up step by step on your screen.

Your screen and your marks→a GitHub Copilot session→live tools draw on a transparent overlay

See it explained

The right picture for every question

Ink Brain decides how to teach. It sketches on the page for diagrams, builds motion graphics for maths and dense text, and models physical things in 3D, narrating each step as it draws.

  • Sketches on the page

    Numbered notes, arrows and highlights drawn onto the figure you circled, one idea at a time.

  • Motion graphics

    Boards where equations rearrange themselves and graphs animate their variables, with real numbers.

  • 3D models

    Models you can turn around, with parts that move on their real hinges, come apart or are cut away.

Motion graphics

Maths that moves

Circle a dense definition and Ink Brain works through it on a board in the style of 3Blue1Brown, with small concrete numbers, narrated step by step.

  • Typeset with KaTeX and checked before anything shows
  • Equations morph from one form into the next
  • Graphs follow the variables as they change

3D models

Turn it around. Take it apart.

Physical things become models built from the picture on your screen, wired up or set in motion one step at a time. Drag a model to look around it.

None of these are videos. Each one is Ink Brain's own rendering engine, running in your browser, replaying the exact output the model wrote.

Works with Copilot

Your Copilot sessions can draw on your screen too

Install the extension and every new Copilot CLI or Copilot app session gets Ink Brain's tools, so it can explain, sketch and speak right where you are working.

  • Send a question from the overlay to a session you already have open with the To: chip
  • A session must be allowed once before it can see your screen
  • Taking control of your Mac always needs its own approval

Privacy

Private by design

Nothing is captured until you ask, and what Ink Brain remembers never leaves your Mac.

  • Nothing until you ask

    Each question sends one screenshot, plus a zoomed crop around your marks, to the Copilot session you chose. The overlay is excluded from screenshots.

  • Voice stays on device

    Speech recognition and the neural voice both run on your Mac, unless you choose to allow Apple's server speech.

  • Memory stays local

    Memory lives in ~/.ink-brain/memory with private file permissions. Screen history skips password managers and is deleted after 30 days.

  • You approve control

    Ink Brain only moves the mouse after you approve the listed steps, and stops when you press Esc, press the shortcut or move the mouse.

  • Sandboxed visuals

    Panels run model-written code in sandboxed frames with no network access, and the overlay blocks web requests.

  • A careful web reader

    Pages are read in a hidden, signed-out window that loads no images or media. Set it to ask before each new site.

Download

Get Ink Brain for your Mac

Free and open source. One command checks your Mac, installs Ink Brain and adds it to your Applications folder.

Download the app

$ curl -fsSL https://inkbrain.app/install.sh | bash

Paste it into Terminal. It installs into ~/.ink-brain/app, adds Ink Brain to your Applications folder and starts it. Run it again any time to update. Read the script

git clone https://github.com/A-Georgiou/ink-brain.git cd ink-brain npm install npm start

Prefer to see every step? Clone it and run it yourself. npm run doctor checks the helper, permissions, screen capture and voices.

You will need

  • macOS 14 or later on Apple silicon or Intel
  • A GitHub Copilot subscription, signed in with Copilot CLI using copilot login
  • Node.js 22.12 or later
  • Xcode Command Line Tools, so the native helper can be built

On first launch

  1. Allow Ink Brain Helper to use Screen Recording, the Microphone and Speech Recognition, and optionally Accessibility.
  2. After switching on Screen Recording, click Restart helper. The voice model, about 90 MB, downloads in the background.
  3. Press ⌥⇧Space, circle anything and ask.

FAQ

Questions, answered

Is Ink Brain free?

Yes. Ink Brain is open source under the MIT licence. It answers using your own GitHub Copilot subscription, through the Copilot SDK.

Which Macs does it run on?

Any Mac on macOS 14 or later, with Apple silicon or Intel. Ink Brain is macOS only for now.

Which model does it use?

Claude Opus 5.5 by default, through Copilot. Set model in ~/.ink-brain/config.json to choose another, and Ink Brain falls back to another vision model if yours is unavailable.

What does it send, and when?

Nothing until you ask. Each question sends one screenshot, plus a zoomed crop around your marks, to the Copilot session you chose. Speech recognition and the voice run on your Mac.

Can I change the shortcut?

Yes. Set hotkey in ~/.ink-brain/config.json, or the INK_BRAIN_HOTKEY environment variable, then restart Ink Brain. Open settings file in the menu bar takes you straight there.

How do I update or uninstall it?

Run the installer again to update. To uninstall, run curl -fsSL https://inkbrain.app/install.sh | bash -s -- --uninstall. Your settings and memory stay in ~/.ink-brain until you delete it.

Is this an official GitHub product?

No. Ink Brain is an independent open source project built on the GitHub Copilot SDK.
